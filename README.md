# MultiPic

Массовая загрузка изображений в TV MODX Revolution: компактные миниатюры, сортировка, название/ALT, скрытие, несколько галерей на ресурсе и подключение через `inputTV` в MIGX.

**Текущая версия: 0.3.0-alpha.** Один пакет поддерживает MODX 2.6+ и MODX 3.x. Проверенная матрица включает MODX 2.6.0, 2.6.5, 2.8.5 и 2.8.6 на PHP 7.4, а также MODX 3.0.6 на PHP 7.4 и MODX 3.2.4 на PHP 8.2. Успешный [прогон совместимости в GitHub Actions](https://github.com/olegvarnavski/multipic/actions/runs/40391782695). Установку и работу на MODX 3 также проверил владелец проекта; миниатюры отображаются в менеджере и на сайте.

Новые фотографии хранятся в папках по ID ресурса; миниатюры — в отдельном восстанавливаемом кеше. [Обновление и перенос старых галерей](docs/STORAGE-PROPOSAL.md).

## Установка

1. Скачайте артефакт `multipic-0.3.0-alpha.transport.zip` из успешного [прогона GitHub Actions](https://github.com/olegvarnavski/multipic/actions/runs/40391782695).
2. В менеджере MODX откройте «Управление пакетами», выберите локальную загрузку и установите `.transport.zip`.
3. Создайте TV, например `gallery`, с типом **MultiPic — галерея изображений**.
4. Укажите максимум файлов и папку, например `multipic/gallery/`. На вкладке «Источники файлов» выберите локальный файловый источник.
5. Назначьте TV нужному шаблону. Откройте ресурс, загрузите фотографии и сохраните ресурс.

После установки появляются категория **MultiPic**, сниппет, плагин, настройки и примеры чанков. Ресурсы и TV на сайте создаются отдельно. При обновлении пользовательские изменения демонстрационных чанков сохраняются.

Сторонние дополнения для самостоятельной работы не нужны. Для загрузки пользователь должен иметь право `file_upload`; ограничения типов источника учитываются. Требования к платформе проверяются валидатором установки. Требуются PHP JSON, PDO MySQL, GD, Fileinfo и EXIF. Для WebP библиотека GD должна поддерживать этот формат. Таблицы InnoDB; рекомендуется MySQL 5.7+/MariaDB. Автоматическая очистка использует MySQL advisory locks.

## Вывод

```modx
[[MultiPic?
    &tv=`gallery`
    &tpl=`multipicItem`
    &tplWrapper=`multipicWrapper`
]]
```

Одна фотография другого ресурса:

```modx
[[MultiPic? &tv=`gallery` &resource=`123` &limit=`1`]]
```

Поддерживаются обычные чанки из админки, статические чанки по имени и файлы через `@FILE`. Примеры сниппета и Fenom `foreach` установлены в категории MultiPic. [Полная справка по текущей реализации](docs/USAGE.md).

## Сборка из исходников

На отдельной установленной копии MODX 2.8.6:

```bash
php _build/build.transport.php /absolute/path/to/site/config.core.php
```

Сборщик создаёт пакет версии 0.3.0-alpha в `core/packages/` используемой установки. Он не публикует пакет и не устанавливает его автоматически.

## Проверки

```bash
php tests/gallery.php
php tests/image.php
php tests/snippet.php
node --check assets/components/multipic/js/multipic.js
node tests/editor.cjs
```

CI устанавливает один пакет, собранный на MODX 2.8.6, на все версии MODX из матрицы. На MODX 3 проверяются TV, моделирование inputTVid/MIGX, медиаисточник, загрузка/сохранение/превью через HTTP, вывод, копирование ресурса, перенос старого формата хранения и CLI. Для разработческих DOM-тестов: `npm ci && npm test`; Node/npm на сайт устанавливать не нужно.

На тестовом сайте ещё требуется ручная приёмка вложенного MIGX, мобильного браузера, Ctrl/Shift в файловом браузере и ограниченных ACL. Не запускайте `tests/integration.php` на рабочем сайте: тест создаёт ресурсы и проверяет физическое удаление своих файлов.
