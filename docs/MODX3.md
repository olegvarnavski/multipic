# MODX 3 — MultiPic 0.3.0-alpha

Один транспортный пакет для MODX 2 и 3. Установка не меняет формат JSON, схему папок, фотографии или шаблоны вывода 0.2.0. Дополнительные компоненты для обычного TV не требуются. Для вложенных галерей нужна совместимая с вашим MODX версия MIGX.

Слой `model/Compat.php` выбирает имена классов ядра и медиаисточников. TV наследует соответствующий рендер через внутреннее имя MultiPicInputRenderBase. Стандартные глобальные алиасы MODX 3 модулю не нужны. Resolver и validator используют транспортные классы своей версии xPDO. CLI загружает Composer-автозагрузчик ядра MODX 3; Composer на рабочем сайте отдельно запускать не требуется.

Проверяемые сочетания: MODX 2.6.0/2.6.5/2.8.5/2.8.6 + PHP 7.4; MODX 3.0.6 + PHP 7.4; MODX 3.2.4 + PHP 8.2. Требования PHP самого ядра обязательны: для MODX 3.2 нужен PHP 8.1+. MODX 4 не заявлен.

На MODX 2 проверяется обновление с настоящего пакета 0.1.3. На MODX 3 выполняется свежая установка того же пакета, собранного на MODX 2.8.6; старое хранилище воспроизводится тестовыми данными, а не установкой несовместимого старого пакета. Полный переход работающего сайта с MODX 2 на MODX 3 этим тестом не воспроизводится.

Тест рендера моделирует синтетический ID и inputTVid MIGX, включая вложенный сериализованный JSON. Реальный сторонний MIGX не устанавливается в CI: окна и его совместимость необходимо проверить на конкретной версии сайта. Копирование, файлы, вывод, очистка и HTTP проверяются на настоящем ядре MODX.
