# Статус 0.3.0-alpha

27.10.2026. Один пакет совместим с MODX 2.6+ и MODX 3.x. Реализованы папки по ресурсу, временный `_incoming/`, отдельный приватный восстанавливаемый кеш превью, повторное использование управляемых файлов и журналируемый перенос старых TV/MIGX.

Полная проверка установки и основных сценариев прошла в GitHub Actions: MODX 2.6.0, 2.6.5, 2.8.5, 2.8.6 / PHP 7.4, MODX 3.0.6 / PHP 7.4 и MODX 3.2.4 / PHP 8.2. [Успешный прогон 40391782695](https://github.com/olegvarnavski/multipic/actions/runs/40391782695). Пакет, собранный на MODX 2.8.6, устанавливается также на MODX 3 с отключёнными глобальными псевдонимами.

На тестовом MODX 3 владелец проекта подтвердил работу пакета и отображение миниатюр в менеджере и на сайте. Владелец проекта также подтвердил, что MIGX работает на MODX 2. Для PHP 8.2 отдельно проходят unit-проверки.

Остаётся ручная проверка вложенного MIGX, особенно на MODX 3, мобильного браузера, Ctrl/Shift в файловом браузере и нескольких редакторов с ограниченными ACL. Прямые URL вне TV/MIGX не отслеживаются. Очистка кандидатов просматривает TV; кеш ресурсов сбрасывается консервативно. Изменение корня сайта или источника требует отдельной проверки путей.
