# Статус 0.2.0-alpha

26.10.2026. Реализованы папки по ресурсу, временный `_incoming/`, отдельный приватный восстанавливаемый кеш превью, повторное использование управляемых файлов и журналируемый перенос старых TV/MIGX.

Локально прошли PHP 7.4 unit/GD и DOM-проверки. Полная проверка установки/обновления, миграции, копирования, удаления и HTTP выполняется в GitHub Actions на MODX 2.6.0, 2.6.5, 2.8.5, 2.8.6 / PHP 7.4 / MySQL 5.7. Результат текущего прогона будет указан после завершения.

MODX 3 не сертифицирован. PHP 8.2 проверяется отдельно на уровне unit. Требуется ручная приёмка вложенных окон MIGX, мобильного браузера, Ctrl/Shift и нескольких редакторов. Прямые URL вне TV/MIGX не отслеживаются. Очистка кандидатов просматривает TV; кеш ресурсов сбрасывается консервативно. Изменение корня сайта/источника требует отдельной проверки путей.
