# Статус 0.1.3-alpha

Целевая ветка: MODX Revolution 2.x начиная с 2.6.0 / PHP 7.4+. MODX 3 отложен и исключён из требований этого установочного пакета.

## Проверено локально

- PHP 7.4.3: синтаксис всех PHP-файлов, модульные проверки галерей и сниппета.
- GD на PHP 7.4: уменьшение, прозрачность, отсутствие увеличения, SEO-транслитерация.
- JSON: активность, odd/even, offset/limit, вложенные сериализованные поля MIGX, повреждённые данные.
- Сниппет: HTML/MODX-экранирование, raw array, запрет выхода @FILE за базовую папку.
- Node: синтаксис редактора и порядок файлов.
- Настоящий Smarty из MODX 2.8.6: компиляция шаблонов поля и его настроек.
- Транспортный пакет собирается штатными классами MODX 2.8.6 под PHP 7.4. Локально использована автономная подстановка workspace без подключённой БД; это не полноценная установка.

## Интеграционная проверка — успешно

[Прогон 39100947199](https://github.com/olegvarnavski/multipic/actions/runs/39100947199) прошёл на MODX 2.6.0, 2.6.5, 2.8.5 и 2.8.6, PHP 7.4.33 и MySQL 5.7. Подтверждены установка транспортного пакета, создание TV, загрузка и дедупликация, серверная проверка данных, вывод установленным сниппетом/чанками, копирование ресурса, сохранность общего файла и физическое удаление последнего использования. В dist сохранён артефакт задания MODX 2.8.5 этого прогона. Также проверен рендер установленного TV и настроек, включая подключение через inputTVid MIGX. Сторонние дополнения не требуются; платформенные ограничения проверяет валидатор без вкладки пакетных зависимостей. Все промежуточные версии MODX 2.x отдельно не проверялись.

Локальная DOM-симуляция также проверила независимые поля, порядок завершения очереди, глазик/подписи и блокировку сохранения ресурса/окна MIGX при незавершённой загрузке. Это не заменяет ручную проверку реального менеджера.

## Требуют ручной приёмки

- Менеджер MODX: обычное TV, несколько полей, реальный файловый браузер, сессии и ограниченные ACL.
- MIGX и вложенный MIGX: сохранение/отмена, дублирование строк, dirty-state, клавиатурное сохранение и передача токенов форм.
- Гонки нескольких пользователей и очистка при одновременном сохранении.
- Fenom и экранирование JSON value при вложении в обычный MODX-тег.
- Телефон: горизонтальная прокрутка, маркер сортировки и увеличенный просмотр.

## Ограничения alpha

- Для кандидатов на физическое удаление выполняется консервативная сверка всех TV MultiPic. Нужна оптимизация на очень больших базах.
- После сохранения галерей сбрасывается общий кеш ресурсов; адресные зависимости ещё не реализованы.
- Все изображения перекодируются GD для удаления метаданных, даже небольшие.
- Дополнительная дедупликация готовых байтов не реализована; исходный SHA-256 + профиль + источник/папка поддержаны.
- Имя галереи из произвольного поля месяца MIGX пока не сопоставляется. Используются исходное имя или заголовок ресурса.
- Восстановление путей после переезда абсолютного корня сайта требует отдельной миграции; до неё не запускать очистку.
- Нет отдельного интерфейса проверки целостности/восстановления.
- Анимация, HEIC/GIF/SVG, удалённые медиаисточники и MIGXdb вне текущего выпуска.
