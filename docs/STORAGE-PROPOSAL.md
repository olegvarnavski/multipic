# Проект новой структуры хранения — не реализовано

26.10.2026. Требования: папки по ID ресурса, без пары каталогов на фото; отдельный очищаемый кеш превью. Существующие файлы пока не перемещать.

Текущие files/xx/yy — корзины по префиксу случайного 128-битного ID. Они переиспользуются: число корзин не ограничивает количество файлов. Полный ID входит в имя. thumbs повторяет структуру. Удалённые превью сейчас не восстанавливаются автоматически; рендер подставляет основной файл, а повторный импорт записи без thumb может завершиться ошибкой.

Предложение:

- Основные файлы: <источник>/<папка TV>/<resourceID>/<SEO-имя>-<fileID>.<ext>. Все галереи ресурса в одной папке.
- Несохранённый ресурс: одна общая _incoming/ с уникальными именами; после получения ID согласованно переместить и обновить реестр, JSON и редактор.
- Превью: {core_path}cache/multipic/thumbs/<ownerID>/<fileID>-<profile>.<ext>, выдача с проверкой доступа менеджера. Отсутствующий кеш воссоздаётся из основного файла; блокировка по файлу и атомарная запись. Не создавать все превью сайта сразу после очистки.
- Сохранить отсутствие дублей при копировании: файл остаётся в папке ресурса первой загрузки, копия хранит ссылку. После удаления страницы-владельца её папка может остаться, пока файл нужен другой странице. Отдельные физические копии в каждой папке требуют места и меняют согласованное поведение.
- Дедупликация по источнику/логической папке TV/профилю/SHA, без ownerID в ключе.

Миграция: сначала read-only отчёт по файлам, ссылкам, источникам, владельцам, новым путям и отсутствующим изображениям. Старый реестр не хранит владельца: выбор из живых ссылок показать в отчёте, не выдавать за исторический ID первой загрузки. Затем резервная копия, журналируемые партии, повторный запуск/откат и совместимость обеих схем на переходе. Обновить все JSON, включая вложенный сериализованный MIGX, а не только пути в реестре. Проверить копирование, удаление владельца, несохранённый ресурс и отмену MIGX. Удалять старые превью только после появления и проверки настоящей регенерации.
