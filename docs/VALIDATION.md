# Проверки 0.2.0-alpha

Локально: синтаксис PHP 7.4, xPDO API/идемпотентная схема, пути и symlink, JSON/вложенный MIGX, GD/6000×4061 при 192M, memory guard, сниппет и DOM редактора. Новая DOM-проверка подтверждает авторизованный POST превью, очередь максимум из двух запросов и переиспользование blob.

CI дополнительно проверяет обновление с 0.1.3, сохранность настроек/чанков/файлов, перенос старого файла и вложенных JSON/копий, откат транзакции при повреждённых данных и продолжение по журналу, перенос `_incoming/`, восстановление удалённой миниатюры, переиспользование управляемого файла и удаление последней ссылки. HTTP проверяет авторизацию превью и новый путь по ID ресурса. [Все пять заданий CI прошли](https://github.com/olegvarnavski/multipic/actions/runs/40334305700): MODX 2.6.0, 2.6.5, 2.8.5, 2.8.6 / PHP 7.4.33 / MySQL 5.7 и отдельный PHP 8.2 unit. Проверенный установщик взят из задания MODX 2.8.6, контрольная сумма проверена при скачивании.

Предыдущая подтверждённая интеграция 0.1.7: https://github.com/olegvarnavski/multipic/actions/runs/40326834479.
