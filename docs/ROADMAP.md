# Дальнейшая работа MultiPic

Обновлено 26.10.2026. Текущая база — 0.3.0-alpha; совместимость MODX 2.6+ и MODX 3.x проверена CI и установкой на тестовом MODX 3.

Осталось, в порядке пользы:

1. Ручная приёмка настоящего MIGX и вложенного MIGX: сохранить/отменить/копировать строку, несколько TV, повторные сохранения, клавиатура, ограниченные ACL. DOM и HTTP обычного TV не заменяют этот этап.
2. Реальная проверка Ctrl/Shift в файловом браузере MODX 2.6/2.8, перетаскивания в конец/начало, телефона и доступности с клавиатуры.
3. Отдельная матрица Fenom, статических/файловых чанков и сложных подписей в MIGX. Задать договорённый способ передачи JSON без вложения пользовательских данных в текст MODX-тега.
4. Утилита переноса путей и URL с предварительным отчётом, согласованной сменой bucket и вложенных JSON. Пока перенос автоматом не делать; --check показывает проблемы, опасное удаление блокируется.
5. Инвентаризация старых бесхозных файлов: только отчёт в известных папках, без удаления по одному совпадению имени.
6. Нагрузочный стенд, несколько PHP workers, гонки одинаковых загрузок, очистки и сторонних импортёров. Уменьшить просмотр TV при очистке, сохранив защиту данных.
7. Адресная инвалидизация кеша с явным учётом зависимостей, включая межресурсный вывод и foreach. До этого сохраняется общий сброс ради корректности.
8. Определить публичную лицензию владельцем проекта до публикации в каталоге. Не назначать лицензию молча.

Временный лимит загрузок действует на редактор, а не на общий диск/пользователя. Глобальные квоты, восстановление превью и интерфейс обслуживания — отдельные последующие задачи.

Исправления по скриншотам 26.10: расчёт памяти и освобождение GD-буферов, browser-resize после отказа PHP, обработка пустых/повторно сериализованных значений MIGX. Осталась приёмка реального Chrome, EXIF на фотографиях пользователя и непустого старого формата gallery (при наличии); старые данные не обнулять.

0.1.6: исправлено повторное открытие файлового браузера, задан новый стандартный лимит 32 Мп, добавлена справка МБ/пиксели, примеры URL без двойного префикса и проверка переименованной админки. Нужна ручная приёмка повторных выборов и самого браузера MODX на сайте пользователя.

0.1.7: квота пикселей удалена, память защищена; крестик preview справа и справка только в МБ. В 0.2.0 добавлены папки по ID ресурса и восстанавливаемый кеш миниатюр — STORAGE-PROPOSAL.md.

0.2.0: структура по ID ресурса и восстанавливаемый кеш реализованы; порядок переноса — STORAGE-PROPOSAL.md.
