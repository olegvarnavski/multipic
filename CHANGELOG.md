# 0.1.4-alpha

- Закрыта подмена width/height в запросах сохранения; HTML-вывод нормализует числа и передаёт чанкам только известные поля, текстовые значения экранируются.
- Общая проверка принадлежности файлов хранилищу перед удалением: пары оригинал/превью, ID/подпапки/имя, существующие локальные источники и отсутствие символьных ссылок.
- Обработка GD вынесена из общей блокировки. Повторная проверка под блокировкой перед регистрацией сохраняет дедупликацию параллельных загрузок.
- Журнал pending отслеживает незавершённые загрузки. Просроченные операции очищаются с проверкой путей; временные загрузки редактора ограничены.
- Очистка выполняется ограниченными партиями, восстанавливает только найденные ссылки кандидатов, не пересоздаёт весь реестр и не загружает все TV в PHP-массив. Добавлен индекс времени leases и версия схемы.
- CLI --check проверяет целостность без удаления и изменения реестра.
- Потерянный файл отображается отдельной карточкой, не блокируя остальные изображения.
- Загрузка учитывает file_upload и разрешённые типы источника. Ошибки получают код запроса и запись в журнал без токенов; ошибки heartbeat видны в редакторе.
- SVG-иконки видимости, место вставки при переносе, множественный выбор записей штатного файлового браузера (Ctrl/Shift), удаление токенов закрытых редакторов.
- Добавлены проверки обновления с 0.1.3 с данными, повторной миграции, безопасных путей/символических ссылок, инъекций размеров, pending-очистки и DOM-проверки сортировки/выбора нескольких файлов. Отдельные unit-проверки на PHP 8.2 не являются проверкой всей MODX на PHP 8.2.

# 0.1.3-alpha

- Токены галерей перенесены из общей PHP-сессии в отдельную служебную таблицу с проверкой пользователя, авторизации и срока действия. Закрытие/перезапись PHP-сессии больше не теряет созданные токены.
- Добавлены HTTP-проверки входа в менеджер, рендера TV, multipart-загрузки и раннего закрытия PHP-сессии.
- Системные параметры получили корректные русские названия и пояснения.
- В параметры TV добавлен штатный выпадающий список существующих источников файлов; настройки сохраняются при использовании inputTV в MIGX.
- Исправлены составные ключи связей в тестовых данных: HTTP-проверка открывает TV в реальном ресурсе.

# 0.1.2-alpha

- Удалены requires-атрибуты платформы, открывавшие вкладку «Зависимости» и блокировавшие MODX 2.8.5.
- Минимальная версия MODX 2 для проверки установки снижена до 2.6.0; проверка PHP 7.4 и расширений сохранена в валидаторе.
- MODX 3 пока не заявлен поддержанным: этот пакет проверяется для ветки MODX 2.x.
- Добавлена матрица PHP 7.4 с MODX 2.6.0, 2.6.5, 2.8.5 и 2.8.6.

# 0.1.1-alpha

- Исправлено обращение к БД: используется API xPDO, а не ошибочное предположение, что getConnection() возвращает PDO.

- Основная тестовая связка уточнена: MODX 2.8.6 / PHP 7.4. Пакет ограничен MODX 2.x и проверяет PHP-расширения при установке.
- Предзагрузка редактора на странице ресурса обеспечивает доступность JS/CSS при открытии поля через MIGX.
- Поддержан исходный inputTVid MIGX; ошибки одного рендера не переходят на другие TV, исходное значение сохраняется при ошибке.
- Сохранение блокируется через beforeSubmit ресурса и doSubmit конкретного окна MIGX, а не только по тексту кнопки.
- Токены редакторов передаются в параметры формы и дублируются в JSON для вложенных галерей.
- Запись ресурса, аренда файлов и очистка используют согласованную блокировку. Ненужная полная сверка не запускается, если нет кандидатов на удаление.
- Уточнены серверные проверки, ASCII-индексы таблиц, наследование пустых настроек, комментарии примеров и dirty-state настроек TV.
- Добавлены сценарии приёмки и workflow установки/проверок на одноразовом MODX 2.8.6.
