# 0.1.2-alpha

- Удалены requires-атрибуты платформы, открывавшие вкладку «Зависимости» и блокировавшие MODX 2.8.5.
- Минимальная версия MODX 2 для проверки установки снижена до 2.6.0; проверка PHP 7.4 и расширений сохранена в валидаторе.
- MODX 3 пока не заявлен поддержанным: этот пакет проверяется для ветки MODX 2.x.
- Добавлена матрица PHP 7.4 с MODX 2.6.0, 2.6.5, 2.8.5 и 2.8.6.

# 0.1.1-alpha

- Исправлено обращение к БД: используется API xPDO, а не ошибочное предположение, что getConnection() возвращает PDO.

- Основная тестовая связка уточнена: MODX 2.8.6 / PHP 7.4. Пакет ограничен MODX 2.x и проверяет PHP-расширения при установке.
- Предзагрузка редактора на странице ресурса обеспечивает доступность JS/CSS при открытии поля через MIGX.
- Поддержан исходный inputTVid MIGX; ошибки одного рендера не переходят на другие TV, исходное значение сохраняется при ошибке.
- Сохранение блокируется через beforeSubmit ресурса и doSubmit конкретного окна MIGX, а не только по тексту кнопки.
- Токены редакторов передаются в параметры формы и дублируются в JSON для вложенных галерей.
- Запись ресурса, аренда файлов и очистка используют согласованную блокировку. Ненужная полная сверка не запускается, если нет кандидатов на удаление.
- Уточнены серверные проверки, ASCII-индексы таблиц, наследование пустых настроек, комментарии примеров и dirty-state настроек TV.
- Добавлены сценарии приёмки и workflow установки/проверок на одноразовом MODX 2.8.6.
